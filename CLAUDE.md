# mandel

Z80 Mandelbrot renderer for a real RC2014 board - optimization/learning
project. Before doing anything in this repo, read:

- `AGENT.md` - device topology (which drive is for what), build commands,
  local toolbox setup, and known gotchas that cost real time to discover.
  Read this first.
- `PLAN.md` - current status, what's done, what's next, backlog.
- `README.md` - project history and measured timings.
